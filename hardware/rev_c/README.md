# SkySweep32 Rev C hardware

> **READY FOR FIRST PHYSICAL PROTOTYPE — NOT PRODUCTION VALIDATED.**
> The package below is the only current fabrication/assembly source. Reproduce
> its gates before ordering and then complete the physical validation checklist.

Rev C is a four-layer, 150 × 95 mm passive-monitor carrier around an
ESP32-S3-WROOM-1-N16R8. Fitted receive paths cover 855–925 MHz (E07/CC1101),
2.4 GHz (E28/SX1281), and 5.8 GHz (RX5808 RSSI). It also includes SAM-M10Q
GNSS, microSD, OLED harness, local controls/alerts, USB-C, a protected 1S battery
path, and ESP32-S3 Wi-Fi/BLE/ESP-NOW.

## Build / order route

1. Read [`BUILD.md`](BUILD.md) for exact tools and fabrication/assembly files.
2. Use [`hardware_manifest.json`](hardware_manifest.json) for exact parts,
   footprints, pins, DNP choices, supplier/manufacturer references, and envelopes.
3. Use [`manufacturing/`](manufacturing/) only after reproducing the current
   evidence with [`tools/hardware/verify.py`](../../tools/hardware/verify.py).
4. Follow [`ASSEMBLY_AND_BRINGUP.md`](ASSEMBLY_AND_BRINGUP.md).
5. Do not advance status without every applicable item in
   [`PROTOTYPE_VALIDATION_CHECKLIST.md`](PROTOTYPE_VALIDATION_CHECKLIST.md).

## Validation boundary

Current evidence records zero current ERC errors/warnings, zero DRC violations,
zero unexpected PCB pads, and CAD enclosure collision/service checks. It does
**not** establish charging safety, antenna behavior, RF sensitivity/selectivity,
GNSS performance, USB integrity, enclosure tolerances, reliability, compliance,
or production yield. Those require an assembled board and measurements.
