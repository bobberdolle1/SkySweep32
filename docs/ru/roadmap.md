# Дорожная карта

Ближайший приоритет — физические доказательства Rev C Prototype #1. Подробности:
[hardware evidence roadmap](../../hardware/rev_c/ROADMAP.md).

1. Собрать, запитать и охарактеризовать Rev C без повышения зрелости одной прозой.
2. Улучшать Rev C только при defect или trade-off, выявленном измерениями.
3. Проводить multi-node эксперименты через ESP-NOW; оценивать корреляцию только
   по реальным timestamps и измерениям.
4. Рассматривать внешний LoRa-class transport только после определения protocol,
   power, coexistence и legal requirements.
5. Оставить 5.8 GHz analog-video/CVBS как отдельный experiment.
6. Рассматривать TinyML только с реальным dataset, воспроизводимым обучением,
   моделью, metrics и физической валидацией.
7. Рассматривать Mini или Rev D только при доказанной необходимости.

Ни один пункт roadmap не является заявлением о текущей возможности.
