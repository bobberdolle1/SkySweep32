# Документация SkySweep32

SkySweep32 — open-source система **пассивного многодиапазонного RF-мониторинга**.
Rev C — её текущая физическая реализация, а не определение всего проекта.

> **Текущая зрелость: ГОТОВ К ПЕРВОМУ ФИЗИЧЕСКОМУ ПРОТОТИПУ.** Для Rev C есть
> CAD и build-доказательства, но нет собранной платы, RF-характеризации,
> результатов соответствия нормам, надёжности или полевых испытаний.

## Политика источников истины

| Факт | Авторитетный источник | Производные материалы |
| --- | --- | --- |
| Схема и геометрия Rev C | KiCad + документация производителей | Gerber, STEP, отчёты |
| Комплектующие и GPIO Rev C | `hardware/rev_c/hardware_manifest.json` | header прошивки, board definition, BOM |
| Поведение прошивки | C++ с `esp32s3_rev_c_passive` | binary, локальный Web UI |
| CAD/build-доказательства | воспроизводимые инструменты и отчёты | текстовые сводки |
| Объяснение продукта | эти EN/RU документы | сайт и README |

Отчёт, рендер или успешная компиляция не являются доказательством RF-параметров
или результата физического прототипа.
