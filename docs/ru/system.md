# Архитектура системы и матрица возможностей

```text
RF-среда
  └─ установленные пассивные тракты: 855–925 МГц · 2.4 ГГц · 5.8 ГГц
       ↓ относительные RSSI / наблюдения активности
Ядро ESP32-S3
  ├─ сбор и обработка активности
  ├─ GNSS-время/позиция
  ├─ журналирование microSD
  ├─ OLED, кнопки, зуммер и вибровыход
  ├─ локальный Wi-Fi Web UI и BLE-приём
  └─ обмен событиями ESP-NOW
       ↓
OLED · SD-журналы · локальный Web UI · оповещения · сетевые события
```

Будущие направления: корреляция узлов, внешний LoRa-class transport, эксперименты
с видео 5.8 ГГц и ML, подтверждённый данными. Это не производственные возможности Rev C.

## Текущая матрица истины

| Область | Состояние исходников | Физические доказательства | Публичный статус |
| --- | --- | --- | --- |
| 855–925 МГц | собирается; CC1101 на 860/890/920 МГц | нет | нужна RF-характеризация прототипа |
| 2.4 ГГц | собирается; RSSI-обзор SX1281 | нет | только энергия/активность |
| 5.8 ГГц | собирается; RX5808 и аналоговый RSSI | нет | нужен входной и стендовый контроль |
| GNSS, microSD, OLED, кнопки, батарея | исходники + контракт Rev C | платы нет | нужен физический запуск |
| Wi-Fi Web UI, ESP-NOW | исходники собираются | запуска/дальности Rev C нет | уникальный AP на устройство; authorization управления/logs; экспериментально на Rev C |
| Remote ID | сохранённый BLE parser | нет association/conformance fixture или hardware test | экспериментальный код отключён по умолчанию |
| MAVLink / CRSF | host-тесты ограниченных parser | нет демодулированного входа Rev C | только parser infrastructure |
| ATAK, LoRa/Meshtastic, TinyML, 5.8 video | текущего product path нет | нет | только roadmap |

SkySweep32 пассивен: он не создаёт помехи, не внедряет данные, не глушит GPS, не
пеленгует и не определяет передатчик по одному RSSI/activity.
